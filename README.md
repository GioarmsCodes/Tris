# Tris Lab

Corso Web & AI per la scuola media: 10 lezioni da 90 minuti, dalla prima pagina HTML a un tris con AI minimax.

Pubblicazione su GitHub Pages: carica il contenuto di questa cartella nella radice del repository, poi Settings > Pages > Deploy from a branch > `main` / `root`. Il sito parte da `index.html`.

I progressi degli studenti si salvano nel loro browser (localStorage).
